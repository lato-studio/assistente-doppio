# Assistente Doppio

O Assistente Doppio é o assistente de IA dos alunos da mentoria Doppio, do Sérgio Nogueira. Faz Reels, carrosséis e legendas com a metodologia Doppio, a partir das tuas fotos, e responde com o que o Sérgio ensina nas aulas.

Só funciona para alunos com a mentoria ativa no Lato.

## Instalar (uma vez)

**1. O plugin**, dentro do Claude Code:
```
/plugin marketplace add lato-studio/assistente-doppio
/plugin install assistente-doppio@doppio
```

**2. As atualizações automáticas.** Em `/plugin`, abre o marketplace `doppio` e liga as atualizações automáticas. Assim recebes as melhorias do motor sem fazer nada. As regras do método atualizam-se sempre sozinhas, porque vêm do Assistente.

**3. Entrar.** Na primeira vez, o Claude Code abre uma página do Assistente Doppio no browser. Escreves o email com que entras no Lato, recebes um código de 6 números por email e escreves-o na página. O login dura uma semana; depois, a página volta a abrir para um código novo. Se a página não abrir sozinha, escreve `/mcp` no Claude Code, escolhe `assistente-doppio` e carrega em entrar.

## Usar

Na primeira vez, abre a pasta Documentos no Claude Code e diz "Vamos começar". O Assistente cria lá a pasta do teu negócio. A partir daí, abre sempre essa pasta e diz, por exemplo:
- "Quero fazer um Reel de prova";
- "Faz o banco de slides deste casamento";
- "Escreve a legenda deste carrossel".

Na primeira vez que fizeres um Reel ou um carrossel, o Assistente instala uma ferramenta gratuita (o uv) e as bibliotecas do motor. O Claude pede-te autorização: carrega em permitir. Demora uns minutos, e só acontece uma vez.

## O que é teu e o que não é

As fotos, os vídeos, a tua ficha e os conteúdos que crias são teus. As regras e o método que o Assistente usa são da mentoria Doppio, licenciados a ti enquanto fores aluno.
